# voicenote — eval site

A single static page presenting the `evals/` harness in the parent repository, and the
reminder-scheduling bug its datetime metric exposed.

**It is not a demo of voicenote.** voicenote is local-only — Vosk is a 40 MB native package and
Ollama is a local server — so nothing here transcribes audio or calls a model. The page reads a
recorded eval run from `public/eval-data.json` and re-scores it in the browser with
`lib/score.mjs`, the JavaScript port of `evals/harness.py`.

## Data

`public/eval-data.json` is generated by, and owned by, the exporter in the parent repository:

```bash
# from the repository root
python -m evals.export_web
```

This app never writes that file. If it is absent the page says so and renders no metrics rather
than placeholder numbers.

## Run

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # static export to out/
npm test        # scorer unit tests (node --test)
```

Node 24, npm 11. Dependencies are `next`, `react`, `react-dom`, and Tailwind + PostCSS +
autoprefixer for the build. No component library, no chart library, no runtime fetches; the only
external request is a Google Fonts stylesheet link.

## Deploy

Vercel, zero configuration. Set the project root to `web/`; the framework preset is Next.js and
`next.config.mjs` sets `output: 'export'`, so the build is fully static. There are no API routes,
no server environment variables and no database.

`public/eval-data.json` must be committed (or regenerated in the build) for the deployed page to
show anything.

## Layout

```
app/page.js            page shell: header, provenance, footer, missing-data state
app/data.js            build-time read of public/eval-data.json
components/EvalApp.js  client island: metric panel, the metric toggle, case explorer
components/shape.js    normalizes scoreAll's output; null/absent ratios render "n/a"
lib/score.mjs          the scorer (owned by the exporter side, not by this app)
```
